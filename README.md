📊 Sentiment Dashboard

🚀 Overview



The Sentiment Dashboard is an interactive tool for analyzing text sentiment. It processes text input (single sentences or CSV datasets) to classify opinions as positive, negative, or neutral, and presents insights through clear visualizations. This project demonstrates practical AI and analytics skills in natural language processing and data visualization.



✨ Features



Real-time sentiment classification



Interactive dashboard for single text input or batch CSV uploads



Visualization of sentiment distribution with charts



Wordclouds for positive and negative texts



Download analyzed results as CSV



🛠️ Tech Stack



Python – backend logic



Streamlit – interactive dashboard



Hugging Face Transformers – sentiment analysis pipeline



Plotly / WordCloud – visualizations



Pandas – data manipulation



⚙️ Installation \& Setup

\# Clone the repository

git clone https://github.com/your-username/sentiment-dashboard.git

cd sentiment-dashboard



\# (Optional) Create virtual environment

python -m venv venv

\# Activate virtual environment:

\# Windows

venv\\Scripts\\activate

\# Mac/Linux

source venv/bin/activate



\# Install dependencies

pip install -r requirements.txt



\# Run the dashboard

streamlit run app.py
